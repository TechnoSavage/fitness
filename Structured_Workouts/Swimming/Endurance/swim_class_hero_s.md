# Swim Class Hero (s) 

**1100m/yds**
**20-25min** 
**moderate intensity**

### Warm up
- 2x 50 Free easy @20s
- 2x 50 Free moderate @20s 

### Drill set
- 2x 50 Catch-up drill moderate @20s
- 2x 50 Kick moderate @20s (no kickboard)

### Main set
- 200 Free easy
- 2x 100 Free moderate @20s
- 4x 50 Free strong @30s

### Warm down
- 2x 50 Choice easy @20s
